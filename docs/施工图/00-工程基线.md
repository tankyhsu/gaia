# 00 框架定位与工程基线

## 1. 产品定义

Gaia 是一个面向企业 AI 应用的、有主张的 Python 开发与运行框架。它通过统一契约、Starter、
自动配置和受控 Runtime，把 Model、Workflow、Context、Tool 与 Policy 装配成应用。Test Kit
位于被测应用外部，不进入线上 Runtime 组件图。

Gaia 的目标用户分为两类：AI 应用开发者和架构师，以及有明确业务想法、希望用场景模板搭建
简单 Demo 的业务构建者。开发者关心框架机制、接入和扩展；业务构建者关心能做什么、需要准备
什么以及如何验证价值。两类用户使用独立的文档入口和阅读路径，不在同一页面混排。咨询交付和
内部平台团队可以使用 Gaia，但它们不是 Gaia 的产品身份。

## 2. 设计原则

### 2.1 约定优于配置

安装 Starter 并提供最小配置即可获得一套可运行默认实现。显式配置永远覆盖默认值，且覆盖原因可查询。

### 2.2 集成而非重造

Gaia 不实现大模型、向量数据库或图编排引擎。它定义契约、生命周期、围栏和装配机制，具体能力由组件提供。

### 2.3 确定性外壳包围概率性能力

模型输出必须经过结构化验证；外部写操作必须经过 Policy、HumanGate、幂等台账和恢复流程。
服务端环境、工具定义和 Adapter 绑定是安全事实，客户端请求不能切换。

### 2.4 配置与运行可解释

每个生效组件都必须回答：谁装配的、为什么装配、读取了哪个 Profile、当前版本是什么、如何替换。

### 2.5 代码与控制台同源

`gaia.yaml`、CLI、Actuator 和可选 Dev Console 都投影同一个配置模型。Dev Console 不是另一套
低代码运行时，也不进入生产服务图。

## 3. 非目标

M1 不做：

- 通用 Agent 聊天前端；
- 拖拽式 Workflow 编辑器；
- 模型训练、微调和推理服务；
- 向量数据库管理平台；
- Kubernetes 控制器和多租户 SaaS；
- Java Runtime；
- 客户业务页面；
- 客户发现、售前材料和项目管理。

## 4. 工程形态

M1 保持 Python 3.12 模块化单体、FastAPI、SQLAlchemy、LangGraph Adapter、可选 React Dev
Console。Docker 只用于可选的本地 PostgreSQL、Redis 开发依赖，不是 Gaia 应用启动方式。
这是框架内核的首个参考实现，不代表未来不能拆包；M1 不以拆仓或微服务证明框架化。

| 领域 | M1 选择 |
| --- | --- |
| 包与环境 | `uv`、`pyproject.toml`、`uv.lock` |
| 配置 | Pydantic v2、YAML、环境变量覆盖 |
| CLI | Python 标准库 `argparse`，入口命令 `gaia` |
| API | FastAPI、OpenAPI、SSE |
| 持久化 | SQLAlchemy 2、框架内置 Alembic 迁移；SQLite 默认档、PostgreSQL 扩展档 |
| Agent 状态 | LangGraph SQLite/PostgreSQL checkpoint、PostgreSQL long-term store、pgvector |
| 缓存与限流 | 可选 Redis CacheProvider 与原子固定窗口 RateLimiter |
| 可靠事件 | PostgreSQL Transactional Outbox；当前仅进程内 Publisher |
| Workflow Adapter | LangGraph |
| Dev Console | React、TypeScript、Vite、Playwright；独立本地开发进程 |
| 测试 | Pytest、Ruff、mypy、架构测试、契约测试、E2E |

## 5. Spring Boot 类比边界

| Spring Boot 概念 | Gaia 概念 |
| --- | --- |
| `SpringApplication` | `GaiaApplication` |
| `application.yml` | `gaia.yaml` |
| Profile | `GaiaProfile` |
| Starter | `GaiaStarter` |
| Auto Configuration | `AutoConfigurator` |
| ApplicationContext | `GaiaApplicationContext` |
| Actuator | `/actuator/*` |
| Spring Boot Admin / Initializr 辅助工具 | Gaia Dev Console |
| Test Starter | Gaia Test Kit：Dataset、Executor、Evaluator、Gate 与 replay |

该类比只用于声明式配置、Starter、Actuator 和测试体验。Gaia 不复制 Spring Bean 容器、注解
扫描或生命周期回调；资源统一使用 ASGI lifespan、异步上下文管理器和 `AsyncExitStack`。成熟
第三方库进入 `integrations/`，可选组合行为进入 `capabilities/`。

## 6. M1 参考体验

```bash
gaia init contract-review \
  --starter model-mock \
  --starter workflow-langgraph \
  --starter policy-controlled

cd contract-review
gaia check
gaia doctor
gaia dev
```

应用启动后：

- `GET /actuator/info` 返回应用与框架版本；
- `GET /actuator/components` 返回组件装配图；
- `GET /actuator/config` 返回脱敏后的生效配置；
- `GET /actuator/health` 返回组件级健康状态；
- `GET /actuator/runtime` 返回近时段 Run、Gate、错误、Outbox 和数据库争用摘要；
- Gaia Dev Console 在开发环境展示概览、组件、运行、只读配置和测试结果。
