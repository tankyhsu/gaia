# 06 代码迁移结果

## 1. 迁移结论

Gaia 已在原有 Runtime 上完成框架内核提取，没有重写已验证的事务和恢复语义。当前公共实现
只位于 `src/gaia/`，参考业务只位于 `examples/controlled_task/`。

早期并列的 `agent-harness-adapter/`、`workflow-scaffold/`、`context-scaffold/`、
`scenario-packs/` 和 `shared-foundation/` 已退役。它们不是兼容入口，也不能继续承载新代码。

## 2. 当前框架内核

| 当前模块 | 职责 |
| --- | --- |
| `contracts/`、`sdk/` | 稳定公共契约和应用作者端口 |
| `application/`、`components/`、`starters/` | 生命周期、组件图与自动装配 |
| `runtime/` | Run、Policy、HumanGate、副作用和恢复不变量 |
| `persistence/` | Runtime、Replay 与 Outbox 持久化和迁移 |
| `integrations/`、`capabilities/` | 成熟 Client 的生命周期绑定与可选组合能力 |
| `model_gateway/` | OpenAI-compatible 模型和 Embedding 实现 |
| `api/`、`actuator/` | Runtime API、SSE 与只读运行投影 |
| `testing/`、`evals/` | Test Kit 与兼容 Replay API |
| `diagnostics/`、`observability/` | 错误、诊断包和通用运行摘要 |

## 3. 参考应用

`controlled-task` 的 State、Workflow、规则、Mock Model、Context 和 Tool 均位于
`examples/controlled_task/`。示例可以依赖 Gaia，`src/gaia/` 不得 import `examples` 或包含
`controlled-task`、组织、资源等参考业务常量。

## 4. 移出框架主入口

客户发现、实施计划、交付验收、诊断工具、售前资产和 Showcase 属于仓库级方法论或独立作品，
不得出现在 Gaia Framework README、Console 或核心实现路径，也不得作为框架安装和运行依赖。

相关实施方法统一保存在 `knowledge-base/40-实施Playbook/`。

## 5. 已完成的关键改造

### 5.1 PersistentRuntimeEngine

Provider 和 Adapter 已通过以下依赖方向注入：

```text
PersistentRuntimeEngine
  <- RuntimeDependencies
       <- GaiaApplicationContext
            <- AutoConfigurator
```

引擎只通过 Protocol 调用：`interpret`、`context.get`、`workflow.invoke/resume`、`tools.execute/reconcile`、`policy.evaluate`。

### 5.2 RunRequest

`scenario_id` 是受长度约束的字符串。Application 的 Workflow Registry 决定是否支持该 ID。

### 5.3 ReplayRunner

由构造函数接收 fixture source 和 Application runner，禁止在模块 import 时绑定 controlled-task 路径。

### 5.4 FastAPI

`create_app()` 从 `GaiaApplication` 或 `GaiaApplicationContext` 创建路由依赖；测试可以注入测试 Application。

### 5.5 Mock

框架仅保留不带业务语义的 test doubles。资源、组织和 Intent 规则迁到示例 Starter。

## 6. 数据迁移

新增 Outbox 持久化；退役未进入最终产品边界的 application/configuration revision 表。
禁止修改历史 Run、Event、Gate、Command 的语义。迁移必须兼容已有数据卷。

## 7. 当前兼容边界

M1 保留：

- controlled-task example 继续使用同一 scenario ID；
- `make dev-api` 继续加载 `examples/controlled_task/gaia.yaml`。

旧并列脚手架目录、配置 revision HTTP API 和对应 ORM 模型不在兼容范围。已有数据库通过
Alembic 迁移退役相关表，历史 Run、Event、Gate 和 Command 保持不变。
