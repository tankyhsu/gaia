# 01 Runtime 兼容公共契约

本文件保留 `afde716` 已验证的 Run、Event、HumanGate、SSE 与错误响应契约。Gaia Framework M1
继续兼容这些端点，但应用、组件、配置和 Actuator 的新增契约以新施工图为准。

`controlled-task`、固定 Mock 组织和资源只属于示例，迁移时不得继续写入通用公共模型。

## 1. 事实源

HTTP 契约以 [`specs/openapi.json`](../../specs/openapi.json) 为唯一机器可读事实源。Pydantic 模型必须与 OpenAPI Schema 一致；FastAPI 生成的 `/openapi.json` 必须通过契约对比测试。

所有时间是 UTC 且必须带时区，序列化为 RFC 3339 `date-time`。当前 Runtime 生成 UUID 字符串；
公共契约不承诺具体 UUID 版本。

## 2. 公共枚举

```text
RunMode = mock | sandbox | customer
RunStatus = received | validated | running | waiting_human | degraded | blocked | succeeded | failed | cancelled
ActorType = model | rule | tool | system | human
EventStatus = started | succeeded | failed | blocked
RiskLevel = low | medium | high
GateStatus = pending | approved | rejected | expired
WriteMode = disabled | approval_required | enabled
CommandStatus = proposed | waiting_approval | approved | executing | succeeded | failed | rejected | unknown
```

P0 不实现补偿流程。`compensated` 等状态不进入 P0 公共枚举；真实客户需要时通过 ADR 扩展。

`RunMode` 当前为兼容字段。服务端以 `runtime.environment` 为事实源；请求 mode 不匹配时不创建
Run，不能用请求字段选择 Adapter 或写入权限。

## 3. 错误码

| 错误码 | HTTP | Run 结果 | 含义 |
| --- | ---: | --- | --- |
| `INVALID_REQUEST` | 422 | 不创建 | Schema 校验失败 |
| `SCENARIO_NOT_FOUND` | 409 | 不创建 | 场景未注册 |
| `IDEMPOTENCY_CONFLICT` | 409 | 不创建 | 相同请求幂等键对应不同 payload |
| `UNAUTHORIZED` | 401 | blocked | 身份不可信 |
| `FORBIDDEN` | 403 | blocked | 角色或数据范围不足 |
| `POLICY_DENIED` | 403/201 | 不创建或 blocked | 身份或场景 Policy 阻断 |
| `ENVIRONMENT_MODE_MISMATCH` | 403 | 不创建 | 请求 mode 与服务端环境不一致 |
| `TOOL_NOT_REGISTERED` | 201 | blocked | Proposal 指向未注册写工具 |
| `TOOL_NOT_ALLOWED` | 201 | blocked | 工具不在场景白名单 |
| `TOOL_ENVIRONMENT_MISMATCH` | 启动失败/201 | blocked | Adapter 不允许当前环境 |
| `TOOL_DEFINITION_MISMATCH` | 201 | blocked/failed | Proposal 或 Adapter 定义与注册定义不一致 |
| `TOOL_ROLE_REQUIRED` | 201 | blocked | 请求者缺少工具角色 |
| `WRITE_DISABLED` | 201 | blocked | 环境或场景禁止写入 |
| `TOOL_ADAPTER_ERROR` | 201 | failed | Adapter 构造或执行异常 |
| `CONTEXT_INSUFFICIENT` | 409 | degraded | 无可靠依据 |
| `MODEL_CAPABILITY_MISSING` | 503 | blocked | Endpoint 缺少必要能力 |
| `MODEL_UNAVAILABLE` | 503 | degraded | 模型不可用或超时 |
| `TOOL_TIMEOUT` | 504 | degraded | 只读工具超时 |
| `SIDE_EFFECT_UNKNOWN` | 409 | blocked | 写入超时且无法确认结果 |
| `HUMAN_GATE_REJECTED` | 409 | blocked | 人工拒绝 |
| `HUMAN_GATE_EXPIRED` | 409 | blocked | 人工门禁过期 |
| `BUDGET_EXCEEDED` | 409 | blocked | 超步数、模型调用或时间预算 |
| `RUN_NOT_RESUMABLE` | 409 | 不变 | 当前状态不允许恢复 |
| `INTERNAL_ERROR` | 500 | failed | 未分类内部错误 |

错误响应必须包含：

- `code`：稳定机器码；
- `message`：不依赖业务上下文的人类可读说明；
- `category`：request、configuration、external_dependency、policy 等运维分类；
- `retryable`：框架判断当前错误是否允许安全重试；
- `operator_action`：下一步通用处理建议；
- `trace_id`：日志和诊断包关联标识；
- `details`：可选结构化详情。

响应不得返回堆栈、凭据或客户内容。业务应用可以在自己的交互层转换最终用户文案，但不得改变
机器码、重试语义或掩盖 Trace ID。

## 4. HTTP API

### 4.1 运行

| Method | Path | 用途 |
| --- | --- | --- |
| `POST` | `/v1/runs` | 创建并执行到终态或人工等待态 |
| `GET` | `/v1/runs/{run_id}` | 查看 Run 快照 |
| `POST` | `/v1/runs/{run_id}/cancel` | 取消未终止 Run |
| `GET` | `/v1/runs/{run_id}/events` | 按序号查看事件 |
| `GET` | `/v1/runs/{run_id}/events/stream` | SSE 追加事件 |

`POST /v1/runs` 必须接受 `Idempotency-Key` Header。相同键和相同 canonical JSON body 返回同一 `run_id`；相同键但 body 不同返回 `IDEMPOTENCY_CONFLICT`。

### 4.2 人工门禁

| Method | Path | 用途 |
| --- | --- | --- |
| `GET` | `/v1/human-gates/{gate_id}` | 查看待决策内容 |
| `POST` | `/v1/human-gates/{gate_id}/decision` | 批准或拒绝并恢复 Run |

决策请求使用 `decision=approved|rejected`，必须包含 `decided_by` 和 `comment`。同一 Gate 重复提交相同决策返回当前 Run；重复提交相反决策返回 409。

### 4.3 回放与诊断

| Method | Path | 用途 |
| --- | --- | --- |
| `POST` | `/v1/evals/replays` | 运行指定或全部固定样本 |
| `GET` | `/v1/evals/replays/{replay_id}` | 查看回放结果 |
| `GET` | `/v1/diagnostics/runs/{run_id}/bundle` | 导出脱敏 JSON 诊断包 |

### 4.4 健康与模型

| Method | Path | 用途 |
| --- | --- | --- |
| `GET` | `/health/live` | 进程存活 |
| `GET` | `/health/ready` | 初始化状态与本次启动恢复结果；无副作用 |
| `GET` | `/v1/model-profiles/current/health` | 当前 ModelEndpointProfile 能力与可用性 |

## 5. SDK Python Protocol

下列签名必须原样实现；可以添加私有方法，不得改变公共方法语义。

```python
class ModelProvider(Protocol):
    async def health(self, profile: ModelEndpointProfile) -> ModelHealth: ...
    async def generate_structured(
        self,
        *,
        profile: ModelEndpointProfile,
        messages: list[ModelMessage],
        output_schema: type[BaseModel],
        timeout_seconds: int,
    ) -> ModelResult: ...

class ContextProvider(Protocol):
    async def get_context(
        self,
        *,
        session: RunSession,
        query: ContextQuery,
    ) -> ContextEnvelope: ...

class ReadTool(Protocol):
    definition: ToolDefinition
    async def execute(self, payload: dict[str, Any]) -> ToolResult: ...

class WriteAdapter(Protocol):
    definition: ToolDefinition
    async def execute(
        self,
        *,
        payload: dict[str, Any],
        idempotency_key: str,
    ) -> ToolResult: ...
    async def reconcile(self, *, idempotency_key: str) -> ToolResult | None: ...

class ScenarioRunner(Protocol):
    @property
    def version_bundle(self) -> VersionBundle: ...
    @property
    def execution_policy(self) -> ExecutionPolicy: ...
    async def run(self, *, run_id: str, request: RunRequest) -> RuntimeOutcome: ...
    def bind_gate(self, *, run_id: str, gate_id: str) -> None: ...
    def resume(self, *, run_id: str, decision: str) -> None: ...

class EventSink(Protocol):
    async def append(self, event: RunEvent) -> None: ...
    async def list_after(self, run_id: str, sequence: int) -> list[RunEvent]: ...
```

`ToolDefinition` 还必须声明 `allowed_environments`。写 Adapter 通过定义与 Factory 一起注册；
Runtime 在 Adapter 实例化前校验环境、角色、风险、工具白名单和写入模式。
`ScenarioRunner` 是 Runtime 唯一的场景执行 SPI；已删除未接入 Runtime 的 `WorkflowPort`。

## 6. SSE 契约

- `Content-Type: text/event-stream`
- `id` 为 `RunEvent.sequence`
- `event` 为 `run.event`
- `data` 为完整 `RunEvent` JSON
- 客户端可用 `Last-Event-ID` 从下一个 sequence 恢复
- 无新事件时每 15 秒输出 `: heartbeat`
- Run 进入终态后发送最后事件并关闭连接
- Run 未进入终态时连接持续等待新事件，不以空轮询次数作为关闭条件
- 服务端检测到客户端断开后停止查询；取消连接不改变 Run 状态

生产默认 `GAIA_SSE_POLL_INTERVAL_SECONDS=0.25`、`GAIA_SSE_HEARTBEAT_SECONDS=15`。测试可以通过应用工厂注入更短间隔，但不得改变公共帧格式。

## 7. Java 边界

P0 不提供 Java 工作流 SDK。`examples/java-spring-client/` 只需证明：

- Spring Boot 可根据 OpenAPI 调用 `POST /v1/runs`；
- 可查询 Run 和提交 HumanGate decision；
- 传递 `Idempotency-Key` 和 `X-Trace-Id`；
- 不引入 LangGraph 或 Gaia Python 内部类型。
