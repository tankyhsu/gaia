# 归档文档

这里存放**已被取代或已完成**的设计、计划与评审文档。保留它们是为了留住决策轨迹——
一次架构决定的价值往往在于当时放弃了什么、以及为什么，而这些只存在于当时的文档里。

## 阅读规则

- **这些是特定时间点的快照，不是当前事实。** 与代码或现行文档冲突时，一律以代码为准。
- **不要编辑它们来"修正"过时的表述。** 把一份 2026-07 的评审报告改成符合今天的结论，
  等于伪造记录，也就毁掉了保留它的唯一理由。需要更新认知时，写新文档。
- 文中出现的旧定位（例如把 Gaia 描述为"AI 版 Spring Boot"）是当时的真实表述，
  刻意保留原样。现行定位见仓库根目录 `README.md`。
